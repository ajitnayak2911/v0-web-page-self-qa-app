# Web Page Self Q&A App

> An intelligent web page self-assessment and Q&A application built with modern web technologies.

## 📋 Overview

Web Page Self Q&A App is a powerful application designed to help users create and manage self-assessment questionnaires and Q&A content for web pages. With an intuitive interface and robust feature set, it streamlines the process of building interactive learning experiences.

## ✨ Features

- 🎨 **Modern UI Components** - Built with Radix UI and Tailwind CSS for a polished user experience
- 📱 **Fully Responsive** - Works seamlessly on desktop, tablet, and mobile devices
- 🌓 **Dark/Light Mode** - Theme support for user preference
- 📊 **Data Visualization** - Charts and analytics with Recharts
- ♿ **Accessible** - WCAG compliant components and keyboard navigation
- ⚡ **Fast Performance** - Optimized with Next.js 16 and React 19
- 🔄 **Real-time Updates** - Instant feedback and auto-save capabilities
- 🎯 **Type-Safe** - Full TypeScript support for reliable code

## 🛠️ Tech Stack

## 🚀 Getting Started

### Prerequisites

- Node.js 18.17 or later
- npm or yarn or pnpm

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ajitnayak2911/v0-web-page-self-qa-app.git
   cd v0-web-page-self-qa-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application.
